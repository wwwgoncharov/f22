# F.22 — дизайн-лаборатория коммерческих пространств

Статический сайт (главная + 6 страниц кейсов), без сборки — чистый HTML/CSS/JS. Готов к заливке на GitHub и деплою на Vercel.

## Структура

```
index.html    — главная страница
projects/     — 6 страниц кейсов
styles.css    — общие стили, анимации, адаптив
script.js     — прелоадер, scroll-reveal, sticky-меню
```

## Как залить на GitHub

1. Создай новый пустой репозиторий на github.com (без README, без .gitignore — они уже есть здесь).
2. В терминале, в этой папке:

```
git remote add origin https://github.com/<твой-логин>/<название-репо>.git
git branch -M main
git push -u origin main
```

(если git ещё не инициализирован здесь — сначала `git init`, `git add .`, `git commit -m "Initial commit"`)

## Как запустить на Vercel

1. Зайди на vercel.com, залогинься через GitHub.
2. New Project → выбери этот репозиторий.
3. Framework Preset — **Other** (это статический сайт, сборка не нужна).
4. Build Command и Output Directory оставь пустыми — Vercel отдаст файлы как есть.
5. Deploy.

После деплоя Vercel даст ссылку вида `название.vercel.app`. Свой домен (например, купленный на Рег.ру) подключается в Project Settings → Domains.

## Важно перед реальным запуском

Фотографии сейчас подтягиваются по временным ссылкам:
- на главной (`index.html`) — с CDN Paper (файл дизайна);
- на страницах проектов (`projects/*.html`) — напрямую с сервера Figma (`figma.com/api/mcp/asset/...`). **Эти ссылки на изображения перестанут работать примерно через 7 дней после 27.09.2026, то есть около 4 октября 2026.**

Перед публикацией обязательно нужно:
- заменить `src` у всех `<img>` в `index.html` и во всех файлах `projects/*.html` на финальные фото (оптимизированные, в `.jpg`/`.webp`), положив их, например, в папку `/images`;
- сделать это до истечения срока действия временных ссылок, иначе картинки перестанут загружаться.
